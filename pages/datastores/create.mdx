---
title: 'Criar Datastore'
openapi: 'POST /datastores'
---

## Request

```bash
curl -X POST https://api.chatvolt.ai/datastores \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Base de Conhecimento",
    "description": "Documentos da empresa"
  }'
```

## Resposta

```json
{
  "data": {
    "id": "ds_abc123",
    "name": "Base de Conhecimento",
    "description": "Documentos da empresa",
    "createdAt": "2026-07-23T10:00:00Z"
  },
  "success": true,
  "error": null
}
```

## Dicas

- **Crie o datastore antes de indexar documentos** — o `id` retornado (`ds_...`) é usado nos endpoints de índice e query.
- Dê nomes descritivos: o `name` aparece nos relatórios e na tela de configuração dos agentes.
- Conecte o datastore a um agente depois para que ele use a base nas respostas.
