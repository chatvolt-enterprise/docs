---
title: 'Deletar Datastore'
openapi: 'DELETE /datastores/{id}'
---

<Warning>A deleção é permanente. Todos os documentos e dados serão perdidos.</Warning>

## Request

```bash
curl -X DELETE https://api.chatvolt.ai/datastores/{datastoreId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Resposta

```json
{
  "data": {
    "id": "ds_abc123",
    "deleted": true
  },
  "success": true,
  "error": null
}
```

## Dicas

- **A deleção remove a base e seus índices** — agentes que usavam o datastore passam a responder apenas com o próprio conhecimento.
- Verifique se algum agente ativo referencia o datastore antes de deletar.
- A operação é irreversível; exporte os documentos antes se precisar de backup.
