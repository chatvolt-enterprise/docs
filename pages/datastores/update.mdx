---
title: 'Atualizar Datastore'
openapi: 'PATCH /datastores/{id}'
---

## Request

```bash
curl -X PATCH https://api.chatvolt.ai/datastores/{datastoreId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Base Atualizada",
    "description": "Nova descrição"
  }'
```

## Resposta

```json
{
  "data": {
    "id": "ds_abc123",
    "name": "Base Atualizada",
    "updatedAt": "2026-07-23T14:00:00Z"
  },
  "success": true,
  "error": null
}
```

## Dicas

- **`PATCH` é parcial**: envie só os campos que mudam; os demais são preservados.
- Renomear a base não afeta os índices nem os agentes conectados.
- Se a base está em processo de indexação, a atualização de metadados é imediata e segura.
