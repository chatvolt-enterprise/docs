---
title: 'Mercado Livre'
openapi: 'GET /mercadolivre/get-products'
---

Obtém produtos do Mercado Livre integrados à plataforma.

## Request

```bash
curl https://api.chatvolt.ai/mercadolivre/get-products \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Response

```json
{
  "products": [
    {
      "id": "MLB123456",
      "title": "Produto Exemplo",
      "price": 99.90
    }
  ]
}
```

## Dicas

- A integração do Mercado Livre deve estar **conectada na organização** antes de chamar este endpoint.
- Use o `id` do produto (ex.: `MLB123456`) como referência para enriquecer a base de conhecimento dos agentes.
- A resposta não usa o envelope padrão (`data`/`success`) — é a resposta crua do Mercado Livre.
