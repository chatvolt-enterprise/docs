---
title: 'Mercado Livre'
openapi: 'GET /mercadolivre/get-products'
---

Obtém produtos do Mercado Livre integrados à plataforma.

## Request

```bash
curl -X GET 'https://api.chatvolt.ai/mercadolivre/get-products?agentId=agent_abc123' \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

### Parâmetros de Query

| Parâmetro | Tipo | Obrigatório | Descrição |
|-----------|------|:-----------:|-----------|
| `agentId` | string |  | ID do agente com o Mercado Livre conectado |
| `query` | string |  | Termo de busca de produtos |
| `threshold` | number |  | Limite mínimo de relevância |
| `maxResults` | number |  | Máx. de resultados |
| `sortByRelevance` | boolean |  | Ordenar por relevância |
| `typoTolerance` | boolean |  | Tolerar erros de digitação |

## Response

```json
{
  "products": [
    {
      "id": "MLB123456",
      "title": "Produto Exemplo",
      "price": 99.90
    }
  ]
}
```

## Dicas

- O **`agentId` na query** identifica o agente com a integração conectada — sem ele o endpoint não sabe de qual conta buscar.
- Use a integração do Mercado Livre **conectada na organização** antes de chamar este endpoint.
- A resposta não usa o envelope padrão (`data`/`success`) — é a resposta crua do Mercado Livre.
