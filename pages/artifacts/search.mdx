---
title: 'Buscar Artefatos'
description: 'Pesquise artefatos por texto livre e filtros de categoria, retornando itens relevantes por semelhança para uso rápido pelos agentes.'
openapi: 'GET /artifacts/search'
---

## Request

```bash
curl -X GET 'https://api.chatvolt.ai/artifacts/search?q=relat%C3%B3rio%20mensal&limit=10' \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

### Parâmetros de Query

| Parâmetro | Tipo | Obrigatório | Descrição |
|-----------|------|:-----------:|-----------|
| `q` | string |  | Termo de busca por nome, descrição ou categoria |
| `ids` | string |  | Lista de IDs específicos (ex.: `id1,id2`) |
| `categoryIds` | string |  | Lista de IDs de categoria (inclui sub-categorias) |
| `mediaTypes` | string |  | Filtrar por tipos de mídia (ex.: `IMAGE,VIDEO`) |
| `limit` | number |  | Máx. de resultados (padrão: 20) |

## Dicas

- Busca semântica por `q` retorna os artefatos mais relevantes — não precisa do termo exato.
- Use `ids` para buscar um conjunto específico de artefatos numa única chamada.
- Se o agente não encontra um artefato, confira os `mediaTypes` (a busca ignora tipos fora do filtro).

```json
{

    }

```
