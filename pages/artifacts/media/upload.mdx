Faz upload de um arquivo de mídia e associa a um artefato.

## Request

```bash
curl -X POST https://api.chatvolt.ai/artifacts/media/upload \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@documento.pdf" \
  -F "artifact_id=art_abc123" \
  -F "name=documento.pdf"
```

### Parâmetros

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `file` | arquivo | ✓ | Arquivo a enviar (multipart) |
| `artifact_id` | string | ✓ | ID do artefato ao qual vincular |
| `name` | string | ✓ | Nome do arquivo |
| `alt_description` | string |  | Texto alternativo |

## Resposta

```json
{
  "data": {
    "id": "media_abc123",
    "name": "documento.pdf",
    "mediaType": "pdf",
    "s3Url": "https://...",
    "altDescription": null
  },
  "success": true,
  "error": null
}
```

## Dicas

- **Upload é multipart (`-F`)**: envie o arquivo real, não base64 — evita estourar limites de corpo.
- Os campos obrigatórios são `artifact_id` (snake_case) e `name`, além do próprio `file`.
- Atualize o `alt_description` depois via `PATCH /artifacts/media/{id}` para acessibilidade e para o agente descrever imagens.
