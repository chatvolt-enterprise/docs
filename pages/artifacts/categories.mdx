---
title: 'Categorias de Artefatos'
description: 'Gerencie categorias para organizar artefatos'
openapi: 'GET /artifact-categories, POST /artifact-categories, GET /artifact-categories/{id}, DELETE /artifact-categories/{id}'
---

## Listar Categorias

```bash
curl -X GET https://api.chatvolt.ai/artifact-categories \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Criar Categoria

```bash
curl -X POST https://api.chatvolt.ai/artifact-categories \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Relatórios",
    "description": "Relatórios mensais e trimestrais"
  }'
```

## Obter Categoria

```bash
curl -X GET https://api.chatvolt.ai/artifact-categories/{categoryId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Atualizar Categoria

```bash
curl -X PUT https://api.chatvolt.ai/artifact-categories/{categoryId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Relatórios Anuais"
  }'
```

## Deletar Categoria

```bash
curl -X DELETE https://api.chatvolt.ai/artifact-categories/{categoryId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```
