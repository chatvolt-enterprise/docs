---
title: 'Obter Artefato'
description: 'Recupere os detalhes completos de um artefato pelo ID, incluindo título, conteúdo, categoria, mídias vinculadas e metadados de criação.'
openapi: 'GET /artifacts/{id}'
---

## Request

```bash
curl -X GET https://api.chatvolt.ai/artifacts/{artifactId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Resposta

```json
{
  "data": {
    "id": "art_abc123",
    "title": "Relatório Mensal",
    "type": "pdf",
    "category": "Relatórios",
    "contentUrl": "https://...",
    "createdAt": "2026-07-23T10:00:00Z",
    "updatedAt": "2026-07-23T12:00:00Z"
  },
  "success": true,
  "error": null
}
```

## Dicas

- O `contentUrl` retornado dá acesso ao conteúdo — use-o para download ou preview no seu sistema.
- Use este endpoint para validar se um artefato existe antes de referenciá-lo em respostas do agente.
- Compare `updatedAt` com a sua última sincronização para detectar atualizações externas.
