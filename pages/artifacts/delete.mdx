---
title: 'Deletar Artefato'
description: 'Remova permanentemente um artefato do sistema pelo ID, apagando também as mídias associadas e liberando o slot na sua organização.'
openapi: 'DELETE /artifacts/{id}'
---

## Request

```bash
curl -X DELETE https://api.chatvolt.ai/artifacts/{artifactId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Deletar em Lote

```bash
curl -X DELETE https://api.chatvolt.ai/artifacts \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "ids": ["art_1", "art_2", "art_3"]
  }'
```

## Resposta

```json
{
  "data": {
    "deleted": true,
    "id": "art_abc123"
  },
  "success": true,
  "error": null
}
```

## Dicas

- **A deleção é permanente** — o artefato sai da sua base de conhecimento e não pode ser recuperado.
- A deleção em lote aceita até uma lista de `ids` numa única chamada — prefira-a para limpezas grandes.
- Verifique se o artefato está referenciado por algum agente antes de deletar, para não quebrar respostas com `sources` antigas.
