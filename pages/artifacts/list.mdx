---
title: 'Listar Artefatos'
description: 'Liste todos os artefatos da sua organização com paginação e filtros para localizar rapidamente conteúdos usados pelos seus agentes.'
openapi: 'GET /artifacts'
---

## Request

```bash
curl -X GET https://api.chatvolt.ai/artifacts \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Resposta

```json
{
  "data": [
    {
      "id": "art_abc123",
      "title": "Relatório Mensal",
      "type": "pdf",
      "category": "Relatórios",
      "createdAt": "2026-07-23T10:00:00Z"
    }
  ],
  "success": true,
  "error": null
}
```

## Dicas

- Use a paginação (`limit`/`offset`) para listas grandes — não traga todos os artefatos de uma vez.
- Para buscas por texto ou filtros avançados, use `GET /artifacts/search` com os parâmetros de query.
- Considere cachear a listagem por alguns minutos se os artefatos mudam pouco, reduzindo chamadas à API.
