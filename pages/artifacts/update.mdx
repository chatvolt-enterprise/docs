---
title: 'Atualizar Artefato'
description: 'Atualize as informações de um artefato existente: título, conteúdo, categoria e outros campos, mantendo o mesmo ID como referência.'
openapi: 'PUT /artifacts/{id}'
---

## Request

```bash
curl -X PUT https://api.chatvolt.ai/artifacts/{artifactId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Relatório Atualizado",
    "categoryId": "cat_xyz"
  }'
```

## Resposta

```json
{
  "data": {
    "id": "art_abc123",
    "title": "Relatório Atualizado",
    "updatedAt": "2026-07-23T14:00:00Z"
  },
  "success": true,
  "error": null
}
```

## Dicas

- **`PUT` substitui o artefato**: envie todos os campos que devem prevalecer (inclusive `content`, se for regenerar).
- Ao trocar só o título ou a categoria, os campos não enviados são redefinidos — para mudança parcial prefira ler primeiro com `GET`.
- Atualizar o `content` reindexa o artefato na busca; aguarde alguns segundos antes de consultar via `search`.
