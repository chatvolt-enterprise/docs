---
title: 'Variáveis de Contato'
openapi: 'GET /contacts/variables'
---

## Listar Variáveis

```bash
curl -X GET https://api.chatvolt.ai/contacts/variables \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Criar Variável

```bash
curl -X POST https://api.chatvolt.ai/contacts/variables \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contactId": "contact_abc123",
    "key": "cargo",
    "value": "Gerente"
  }'
```

## Listar Variáveis Disponíveis

```bash
curl -X GET https://api.chatvolt.ai/contacts/available-variables \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Dicas

- **Variáveis de contato são persistidas** e podem ser usadas nos templates de mensagem e nas respostas do agente.
- Use chaves estáveis (ex.: `cargo`, `plano`) — renomear uma chave perde o histórico do valor anterior.
- A listagem de variáveis disponíveis mostra as chaves padrão do sistema; as customizadas criadas via POST aparecem junto.
