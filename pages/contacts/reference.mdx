---
title: 'Contatos'
description: 'Gerencie os contatos dos seus agentes'
---

Contatos representam os usuários finais que interagem com seus agentes. Cada contato pode ter informações de perfil, variáveis customizadas e histórico de conversas.

## Endpoints

| Método | Path | Descrição |
|--------|------|-----------|
| `GET` | `/contacts` | Listar contatos |
| `POST` | `/contacts` | Criar contato |
| `GET` | `/contacts/{id}` | Obter contato |
| `PATCH` | `/contacts/{id}` | Atualizar contato |
| `DELETE` | `/contacts/{id}` | Deletar contato |
| `GET` | `/contacts/variables` | Listar variáveis de contato |
| `GET` | `/contacts/available-variables` | Variáveis disponíveis |
| `POST` | `/contacts/batch-create` | Criar contatos em lote |
| `POST` | `/contacts/merge` | Mesclar contatos duplicados |
| `GET` | `/contacts/export` | Exportar contatos |
| `POST` | `/contacts/import-csv` | Importar contatos por CSV |

## Exemplo: Criar Contato

```bash
curl -X POST https://api.chatvolt.ai/contacts \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "joao@exemplo.com",
    "name": "João Silva",
    "phone": "5511988887777"
  }'
```
