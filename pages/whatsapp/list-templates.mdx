---
title: 'Listar Templates Meta'
openapi: 'GET /whatsapp/templates'
---

Lista todos os templates de mensagem da conta WhatsApp Business associada.

## Request

```bash
curl https://api.chatvolt.ai/whatsapp/templates \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Response

```json
{
  "templates": [
    {
      "id": "123456",
      "name": "boas_vindas",
      "status": "approved",
      "category": "MARKETING"
    }
  ]
}
```

## Dicas

- Use o `status` para mostrar na sua UI se o template já pode ser enviado (`approved`).
- O nome retornado (`boas_vindas`) é usado em `POST /whatsapp/{phoneNumberId}/template-message`.
- Templates rejeitados podem ser editados e reenviados pela API de criação.
