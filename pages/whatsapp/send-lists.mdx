Envia uma mensagem interativa com um menu de opções agrupadas em seções.

## Request

```bash
curl -X POST https://api.chatvolt.ai/messages/interactive/send-lists \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "agent_abc123",
    "conversationId": "conv_abc123",
    "body_text": "Escolha um produto:",
    "button_text": "Ver opções",
    "list_title": "Nossos produtos"
  }'
```

### Parâmetros

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `agentId` | string | ✓ | ID do agente responsável |
| `conversationId` | string | ✓ | ID da conversa |
| `body_text` | string | ✓ | Texto da mensagem (snake_case) |
| `button_text` | string | ✓ | Texto do botão da lista |
| `list_title` | string |  | Título do menu |
| `header_text` / `footer_text` | string |  | Cabeçalho / rodapé |

## Resposta

```json
{
  "data": {
    "messageId": "wamid_abc123",
    "status": "sent"
  },
  "success": true,
  "error": null
}
```

## Dicas

- O contrato usa `body_text`, `button_text` e `list_title` (snake_case) — não `sections`/`rows`.
- Listas são ideais para menus com muitas opções onde botões (máx. 3) ficam apertados.
- As opções configuradas no template/dashboard da integração são exibidas ao abrir o menu.
