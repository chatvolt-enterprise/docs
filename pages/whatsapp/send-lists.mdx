---
title: 'Enviar Lista Interativa'
openapi: 'POST /messages/interactive/send-lists'
---

## Request

```bash
curl -X POST https://api.chatvolt.ai/messages/interactive/send-lists \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "5511988887777",
    "bodyText": "Escolha um produto:",
    "buttonText": "Ver opções",
    "sections": [
      {
        "title": "Produtos",
        "rows": [
          { "id": "prod_1", "title": "Produto A", "description": "R$ 49,90" },
          { "id": "prod_2", "title": "Produto B", "description": "R$ 99,90" }
        ]
      }
    ]
  }'
```

### Parâmetros

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `to` | string |  | Telefone do destinatário |
| `bodyText` | string |  | Texto da mensagem |
| `buttonText` | string |  | Texto do botão da lista |
| `sections` | array |  | Seções com opções |

## Resposta

```json
{
  "data": {
    "messageId": "wamid_abc123",
    "status": "sent"
  },
  "success": true,
  "error": null
}
```
