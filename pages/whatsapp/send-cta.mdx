Envia uma mensagem com um botão que abre uma URL (call to action).

## Request

```bash
curl -X POST https://api.chatvolt.ai/messages/interactive/send-cta \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "agent_abc123",
    "conversationId": "conv_abc123",
    "body_text": "Acesse nosso site!",
    "button_display_text": "Saiba mais",
    "button_url": "https://chatvolt.ai"
  }'
```

### Parâmetros

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `agentId` | string | ✓ | ID do agente responsável |
| `conversationId` | string | ✓ | ID da conversa |
| `body_text` | string | ✓ | Texto da mensagem (snake_case) |
| `button_display_text` | string | ✓ | Texto do botão |
| `button_url` | string | ✓ | URL do CTA (HTTPS) |
| `header_text` / `footer_text` | string |  | Cabeçalho / rodapé |

## Resposta

```json
{
  "data": {
    "messageId": "wamid_abc123",
    "status": "sent"
  },
  "success": true,
  "error": null
}
```

## Dicas

- Os campos do contrato são `button_display_text` e `button_url` (snake_case).
- Use **HTTPS** e links móveis (deep links) quando possível.
- CTA para fora do WhatsApp só em conversas já iniciadas.
