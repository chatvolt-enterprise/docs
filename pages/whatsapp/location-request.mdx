---
title: 'Solicitar Localização'
openapi: 'POST /messages/interactive/location-request'
---

Envia uma mensagem solicitando que o usuário compartilhe sua localização atual. WhatsApp apenas.

## Request

```bash
curl -X POST https://api.chatvolt.ai/messages/interactive/location-request \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "5511988887777",
    "bodyText": "Compartilhe sua localização para encontrarmos a loja mais próxima"
  }'
```

### Parâmetros

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `to` | string | Telefone do destinatário |
| `bodyText` | string | Texto da mensagem |

## Dicas

- O destinatário recebe um botão para compartilhar a localização — use para logística (encontrar lojas, entregas).
- O `to` precisa de DDI+DDD sem `+` (ex.: `5511988887777`).
- Combine com o endpoint de recebimento de mensagens para capturar a localização enviada pelo usuário.
