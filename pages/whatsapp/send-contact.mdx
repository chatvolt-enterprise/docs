Envia um cartão de contato interativo dentro de uma conversa.

## Request

```bash
curl -X POST https://api.chatvolt.ai/messages/interactive/send-contact \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "agent_abc123",
    "conversationId": "conv_abc123",
    "name_formatted_name": "Suporte Chatvolt"
  }'
```

### Parâmetros

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `agentId` | string | ✓ | ID do agente responsável |
| `conversationId` | string | ✓ | ID da conversa |
| `name_formatted_name` | string | ✓ | Nome exibido no cartão (snake_case) |

## Dicas

- Útil para compartilhar **contatos de atendimento** (suporte, financeiro) dentro da conversa.
- O campo obrigatório do contrato é `name_formatted_name` — o número vinculado vem da configuração da integração.
- O envio acontece na conversa identificada por `conversationId`, não por um `to` livre.
