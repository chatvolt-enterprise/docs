---
title: 'Popular Fila do Disparo'
openapi: 'POST /dispatches/{id}/populate-queue'
---

Após configurar o disparo e adicionar contatos, use este endpoint para popular a fila de envio.

## Request

```bash
curl -X POST https://api.chatvolt.ai/dispatches/{dispatchId}/populate-queue \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Resposta

```json
{
  "data": {
    "id": "dispatch_abc123",
    "queueSize": 150,
    "status": "queued"
  },
  "success": true,
  "error": null
}
```

## Dicas

- **Só use após adicionar os contatos** ao disparo — a fila é montada a partir deles.
- O `queueSize` retornado mostra quantos envios serão feitos; confira antes de disparar em massa.
- Depois de `queued`, o envio roda em background — acompanhe o progresso via `GET /dispatches`.
