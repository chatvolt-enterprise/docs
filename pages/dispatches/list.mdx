---
title: 'Listar Disparos'
description: 'Liste todos os disparos em massa cadastrados na sua organização, com status de envio, canal utilizado, agendamento e métricas de entrega.'
openapi: 'GET /dispatches'
---

## Request

```bash
curl -X GET https://api.chatvolt.ai/dispatches \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Resposta

```json
{
  "data": [
    {
      "id": "dispatch_abc123",
      "name": "Campanha Julho",
      "channel": "whatsapp",
      "status": "sent",
      "totalContacts": 150,
      "sentCount": 150,
      "createdAt": "2026-07-23T10:00:00Z"
    }
  ],
  "success": true,
  "error": null
}
```

## Dicas

- Use `sentCount`/`totalContacts` para acompanhar o progresso de disparos em andamento.
- Filtre por status (`draft`, `queued`, `sent`) para separar campanhas concluídas das que precisam de ação.
- A listagem retorna o resumo das campanhas; detalhes de cada envio vêm nos endpoints específicos de dispatch.
