---
title: 'Definir Prioridade'
openapi: 'POST /conversations/{conversationId}/set-priority'
---

Define a prioridade de uma conversa.

## Request

```bash
curl -X POST https://api.chatvolt.ai/conversations/123/set-priority \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "priority": "high"
  }'
```

### Parâmetros de Path

| Parâmetro | Descrição |
|-----------|-----------|
| `conversationId` | ID da conversa |

### Parâmetros do Body

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `priority` | string |  | Prioridade (`low`, `medium`, `high`) |

## Response

```json
{
  "success": true
}
```

## Dicas

- Use prioridades para **SLA de atendimento**: filtre a fila por `high` e atenda primeiro as conversas críticas.
- Ao resolver uma conversa, o status deixa de ser `active` — combina com `set-status` para fechar o fluxo completo.
- Valores válidos: `low`, `medium` e `high`; o padrão é `normal` na criação.
