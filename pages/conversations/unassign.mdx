---
title: 'Remover Atribuição'
openapi: 'POST /conversations/{conversationId}/unassign'
---

Remove o usuário atualmente atribuído a uma conversa.

## Request

```bash
curl -X POST https://api.chatvolt.ai/conversations/123/unassign \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

### Parâmetros de Path

| Parâmetro | Descrição |
|-----------|-----------|
| `conversationId` | ID da conversa |

## Response

```json
{
  "success": true,
  "message": "Conversation unassigned."
}
```

## Dicas

- Use após o atendente encerrar o turno — a conversa volta para a fila geral e pode ser pega por qualquer usuário.
- Consulte quem está atribuído via `GET /conversation/{conversationId}` antes de remover.
- Para trocar de responsável, não precisa remover: chame `assign` com o novo `assigneeId`.
