---
title: 'Enviar Mensagem'
openapi: 'POST /conversation/message/{type}/{value}'
---

Envia uma mensagem para uma conversa em um canal específico (WhatsApp, Telegram, webchat, etc.).

## Request

```bash
curl -X POST https://api.chatvolt.ai/conversation/message/whatsapp/5511988887777 \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Olá! Como posso ajudar?",
    "agentId": "agent_abc123",
    "channel": "whatsapp"
  }'
```

### Parâmetros de Path

| Parâmetro | Descrição |
|-----------|-----------|
| `type` | Tipo do canal (`whatsapp`, `telegram`, `instagram`, `webchat`, etc.) |
| `value` | Identificador do destinatário (telefone, user ID, etc.) |

### Parâmetros do Body

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `message` | string | ✓ | Conteúdo da mensagem |
| `agentId` | string |  | ID do agente para processar a resposta |
| `channel` | string |  | Canal (`website`, `dashboard`, `whatsapp`, `zapi`, `telegram`, `instagramDm`) |
| `attachments` | array |  | Anexos da mensagem |
| `visitorId` | string |  | ID do visitante |
| `contactId` | string |  | ID de contato existente |

## Resposta

```json
{
  "data": {
    "messageId": "msg_abc123",
    "conversationId": "conv_abc123",
    "status": "sent"
  },
  "success": true,
  "error": null
}
```

## Dicas

- O path usa `{channel}/{value}`: para WhatsApp o `value` é o **DDI+DDD+número** (ex.: `5511988887777`), sem `+` nem espaços.
- **Não existe `type` no body** — o canal vai no path; `channel` opcional reforça a origem da mensagem.
- Passe `agentId` quando quiser que o agente processe a resposta automaticamente após o envio.
