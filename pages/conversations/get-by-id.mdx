---
title: 'Obter Conversa'
description: 'Recupere os detalhes de uma conversa específica pelo ID, incluindo canal, status, participantes, tags e demais metadados do atendimento.'
openapi: 'GET /conversation/{conversationId}'
---

## Request

```bash
curl -X GET https://api.chatvolt.ai/conversation/{conversationId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Resposta

```json
{
  "data": {
    "id": "conv_abc123",
    "agentId": "agent_xyz",
    "channel": "whatsapp",
    "status": "active",
    "priority": "normal",
    "aiEnabled": true,
    "contactId": "contact_456",
    "createdAt": "2026-07-23T10:00:00Z",
    "updatedAt": "2026-07-23T12:00:00Z"
  },
  "success": true,
  "error": null
}
```

## Dicas

- Consulte este endpoint antes de montar a tela de detalhe do atendimento: ele traz canal, status, prioridade e `aiEnabled` num único request.
- Use `agentId` e `contactId` retornados para navegar para as páginas do agente e do contato.
- O `status` e o `priority` podem ser alterados depois via `set-status` e `set-priority`.
