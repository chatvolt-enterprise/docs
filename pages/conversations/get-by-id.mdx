---
title: 'Obter Conversa'
description: 'Recupere os detalhes de uma conversa'
openapi: 'GET /conversation/{conversationId}'
---

## Request

```bash
curl -X GET https://api.chatvolt.ai/conversation/{conversationId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Resposta

```json
{
  "data": {
    "id": "conv_abc123",
    "agentId": "agent_xyz",
    "channel": "whatsapp",
    "status": "active",
    "priority": "normal",
    "aiEnabled": true,
    "contactId": "contact_456",
    "createdAt": "2026-07-23T10:00:00Z",
    "updatedAt": "2026-07-23T12:00:00Z"
  },
  "success": true,
  "error": null
}
```
