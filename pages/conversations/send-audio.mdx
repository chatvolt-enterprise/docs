---
title: 'Enviar Áudio'
description: 'Envie uma mensagem de áudio em uma conversa existente informando arquivo, URL ou base64 para responder o contato pelo canal configurado.'
openapi: 'POST /conversations/{conversationId}/send-audio'
---

## Request

```bash
curl -X POST https://api.chatvolt.ai/conversations/{conversationId}/send-audio \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "audioUrl": "https://meusite.com/audio.mp3",
    "duration": 30
  }'
```

### Parâmetros

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `audioUrl` | string |  | URL pública do arquivo de áudio |
| `duration` | number |  | Duração em segundos |

## Resposta

```json
{
  "data": {
    "messageId": "msg_abc123",
    "status": "sent"
  },
  "success": true,
  "error": null
}
```

## Dicas

- O `audioUrl` precisa ser uma **URL pública acessível pelo Chatvolt** (o servidor baixa o arquivo, não o navegador).
- Envie `duration` em segundos para o canal exibir o tempo correto do áudio.
- Formatos aceitos variam por canal — para WhatsApp, prefira `.mp3` ou `.ogg`; evite arquivos acima de 16MB.
