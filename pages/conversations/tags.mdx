## Endpoints

| Método | Path | Descrição |
|--------|------|-----------|
| `GET` | `/conversations/{id}/tags` | Listar tags da conversa |
| `POST` | `/conversations/{id}/tags` | Adicionar tag à conversa |
| `DELETE` | `/conversations/{id}/tags` | Remover tag da conversa |

## Listar Tags

```bash
curl -X GET https://api.chatvolt.ai/conversations/{conversationId}/tags \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Adicionar Tag

```bash
curl -X POST https://api.chatvolt.ai/conversations/{conversationId}/tags \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "tagName": "urgente"
  }'
```

## Resposta

```json
{
  "data": [
    { "id": "tag_abc123", "name": "urgente", "color": "red" }
  ],
  "success": true,
  "error": null
}
```
