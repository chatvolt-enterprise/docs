---
title: 'Atualizar Status'
openapi: 'POST /conversations/{conversationId}/set-status'
---

Atualiza o status de uma conversa (aberta, resolvida, etc.).

## Request

```bash
curl -X POST https://api.chatvolt.ai/conversations/123/set-status \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "resolved"
  }'
```

### Parâmetros de Path

| Parâmetro | Descrição |
|-----------|-----------|
| `conversationId` | ID da conversa |

### Parâmetros do Body

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `status` | string |  | Novo status (`open`, `resolved`, `pending`) |

## Response

```json
{
  "success": true
}
```

## Dicas

- **`resolved` encerra a conversa** — ela sai da fila de atendimento ativa; consulte o formato completo via `GET /conversation/{conversationId}`.
- Use `pending` para aguardar ação externa (ex.: o cliente responder) sem fechar o atendimento.
- Status inválidos retornam erro de validação — confira os valores suportados antes de enviar.
