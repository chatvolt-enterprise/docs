---
title: 'Deletar Conversa'
openapi: 'DELETE /conversation/{conversationId}'
---

<Warning>A deleção é permanente. Todas as mensagens da conversa serão perdidas.</Warning>

## Request

```bash
curl -X DELETE https://api.chatvolt.ai/conversation/{conversationId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Resposta

```json
{
  "data": {
    "id": "conv_abc123",
    "deleted": true
  },
  "success": true,
  "error": null
}
```

## Dicas

- **A deleção é permanente** — mensagens, anexos e histórico da conversa somem sem recuperação.
- Confirme em duas etapas no seu fluxo (ex.: input com "DELETAR") antes de chamar o endpoint.
- Prefira arquivar ou resolver (`POST set-status` com `resolved`) quando precisar apenas tirar a conversa da fila de atendimento.
