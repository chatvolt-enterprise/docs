A whitelist do WhatsApp define quais números de telefone estão autorizados a interagir com o agente via WhatsApp. Fora da whitelist, as mensagens são ignoradas.

## Endpoints

| Método | Path | Descrição |
|--------|------|-----------|
| `GET` | `/agent-whitelist-whatsapp/{id}` | Obter whitelist |
| `POST` | `/agent-whitelist-whatsapp` | Adicionar à whitelist |
| `PATCH` | `/agent-whitelist-whatsapp/{id}` | Atualizar whitelist |
| `DELETE` | `/agent-whitelist-whatsapp/{id}` | Remover da whitelist |

## Listar Whitelist

```bash
curl -X GET https://api.chatvolt.ai/agent-whitelist-whatsapp/{agentId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Adicionar à Whitelist

```bash
curl -X POST https://api.chatvolt.ai/agent-whitelist-whatsapp \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "agent_abc123",
    "phoneNumber": "5511988887777"
  }'
```

### Parâmetros

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `agentId` | string |  | ID do agente |
| `phoneNumber` | string |  | Número a autorizar |

## Remover da Whitelist

```bash
curl -X DELETE https://api.chatvolt.ai/agent-whitelist-whatsapp/{agentId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```
