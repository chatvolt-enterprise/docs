Configura uma URL para receber notificações de eventos do agente (nova mensagem, conversa criada, etc.).

## Request

```bash
curl -X PATCH https://api.chatvolt.ai/agents/{agentId}/webhook \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "webhookUrl": "https://meusistema.com/webhook"
  }'
```

### Parâmetros

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `webhookUrl` | string |  | URL para receber os eventos |

## Resposta

```json
{
  "data": {
    "id": "agent_abc123",
    "webhookUrl": "https://meusistema.com/webhook",
    "updatedAt": "2026-07-23T14:00:00Z"
  },
  "success": true,
  "error": null
}
```

## Dicas

- A URL precisa ser **HTTPS e acessível publicamente** — o Chatvolt envia os eventos do servidor, não do navegador.
- Responda `200` rápido: se o endpoint demorar ou falhar, o Chatvolt fará novas tentativas.
- Use uma URL única por serviço (ex.: `meusistema.com/webhook/agente-vendas`) para facilitar o rastreio nos logs.
