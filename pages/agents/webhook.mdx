title: 'Webhook do Agente'
description: 'Ative ou desative o webhook de um serviço (WhatsApp, Telegram, Z-API, Instagram) de um agente no Chatvolt.'
openapi: 'PATCH /agents/{id}/webhook'
---

Ativa ou desativa o webhook de um serviço de mensageria associado ao agente. Este endpoint é um **toggle de status** — não configura URLs.

## Request

```bash
curl -X PATCH 'https://api.chatvolt.ai/agents/{agentId}/webhook?type=whatsapp&enabled=true' \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

### Parâmetros de Query

| Parâmetro | Tipo | Obrigatório | Descrição |
|-----------|------|:-----------:|-----------|
| `id` | string | ✓ | ID do agente (path) |
| `type` | string | ✓ | Serviço: `whatsapp`, `telegram`, `zapi` ou `instagram` |
| `enabled` | boolean | ✓ | `true` para ativar, `false` para desativar |

## Resposta

```json
{
  "data": {
    "id": "agent_abc123",
    "webhookType": "whatsapp",
    "webhookEnabled": true,
    "updatedAt": "2026-07-23T14:00:00Z"
  },
  "success": true,
  "error": null
}
```

## Dicas

- **O contrato é um toggle**: parámetros `type` + `enabled` na query — o endpoint não aceita body.
- `enabled: true` para o serviço passam a enviar eventos ao webhook configurado na plataforma; `false` interrompe.
- Para `instagram`, ativar o webhook também controla `answerDms` e `answerComments` do agente.
