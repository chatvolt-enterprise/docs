---
title: 'Blacklist de Agente'
description: 'Gerencie a blacklist de números bloqueados para um agente'
openapi: 'GET /agent-blacklist, POST /agent-blacklist, DELETE /agent-blacklist/{agentId}'
---

A blacklist permite bloquear números de telefone ou IDs de usuário de interagirem com um agente específico.

## Endpoints

| Método | Path | Descrição |
|--------|------|-----------|
| `GET` | `/agent-blacklist` | Listar blacklist |
| `POST` | `/agent-blacklist` | Adicionar à blacklist |
| `GET` | `/agent-blacklist/{agentId}` | Obter blacklist de um agente |
| `DELETE` | `/agent-blacklist/{agentId}` | Remover da blacklist |

## Listar Blacklist

```bash
curl -X GET https://api.chatvolt.ai/agent-blacklist \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Adicionar à Blacklist

```bash
curl -X POST https://api.chatvolt.ai/agent-blacklist \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "agent_abc123",
    "phoneNumber": "5511999999999",
    "reason": "Spam"
  }'
```

### Parâmetros

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `agentId` | string |  | ID do agente |
| `phoneNumber` | string |  | Número a bloquear |
| `reason` | string |  | Motivo do bloqueio |

## Remover da Blacklist

```bash
curl -X DELETE https://api.chatvolt.ai/agent-blacklist/{agentId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Resposta

```json
{
  "data": {
```
