---
title: 'Remover da Blacklist'
description: 'Desbloqueie um número de telefone ou ID de usuário de um agente no Chatvolt.'
openapi: 'DELETE /agent-blacklist/{agentId}'
---

Remove um identificador da blacklist de um agente, liberando novas interações.

## Request

```bash
curl -X DELETE 'https://api.chatvolt.ai/agent-blacklist/{agentId}?id=bl_abc123' \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

### Parâmetros

| Parâmetro | Local | Obrigatório | Descrição |
|-----------|-------|:-----------:|-----------|
| `agentId` | path | ✓ | ID do agente |
| `id` | query | ✓ | ID da entrada da blacklist (`bl_...`) a remover |

## Resposta

```json
{
  "data": {
    "id": "bl_abc123",
    "agentId": "agent_abc123",
    "phoneNumber": "5511999999999",
    "reason": "Spam",
    "deleted": true
  },
  "success": true,
  "error": null
}
```

## Dicas

- A remoção é imediata — o número volta a poder falar com o agente na próxima mensagem.
- **O `id` da query é obrigatório** e seleciona a entrada: use o `id` (`bl_...`) retornado na listagem.
- O `agentId` no path não seleciona a entrada — ele identifica o agente, e o `id` qualifica o registro.
