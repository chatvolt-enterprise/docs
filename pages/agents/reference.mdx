Agentes são a unidade principal do Chatvolt. Cada agente é um chatbot de IA personalizado, treinado com seus dados e configurado com ferramentas, canais e comportamentos específicos.

## Endpoints

| Método | Path | Descrição |
|--------|------|-----------|
| `GET` | `/agents` | Listar agentes |
| `POST` | `/agents/create` | Criar agente |
| `GET` | `/agents/{id}` | Obter agente |
| `PATCH` | `/agents/{id}` | Atualizar agente |
| `DELETE` | `/agents/{id}` | Deletar agente |
| `POST` | `/agents/{id}/query` | Enviar query (streaming ou JSON) |
| `POST` | `/agents/{id}/webhook` | Configurar webhook |
| `GET` | `/agents/models` | Listar modelos disponíveis |

## Autenticação

Todos os endpoints de agente exigem o header:

```
Authorization: Bearer SUA_CHAVE_API
```

[Saiba como obter sua chave](/authentication).
