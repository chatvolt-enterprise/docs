Cria um novo agente na organização.

## Request

```bash
curl -X POST https://api.chatvolt.ai/agents \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Meu Agente",
    "description": "Agente de suporte ao cliente",
    "modelName": "gpt-4o",
    "temperature": 0.7
  }'
```

### Parâmetros

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `name` | string | ✓ | Nome do agente |
| `description` | string |  | Descrição |
| `modelName` | string |  | Modelo de IA (padrão: configurado no plano) |
| `temperature` | number |  | 0.0 a 1.0 |

## Resposta

```json
{
  "data": {
    "id": "agent_abc123",
    "name": "Meu Agente",
    "description": "Agente de suporte ao cliente",
    "modelName": "gpt-4o",
    "temperature": 0.7,
    "createdAt": "2026-07-23T10:00:00Z"
  },
  "success": true,
  "error": null
}
```

## Dicas

- **Leve a chave da API no header `Authorization`** em todas as chamadas — sem ela a API retorna `401 Unauthorized`.
- **`name` é obrigatório**; os demais campos têm padrão do plano. Crie primeiro com o mínimo e ajuste depois via `PATCH /agents/{id}`.
- **`temperature` entre 0.0 e 1.0**: valores mais baixos deixam as respostas mais previsíveis; mais altos, mais criativas.
- O `id` retornado (`agent_abc123`) é usado nos endpoints de conversa, query e atualização.
