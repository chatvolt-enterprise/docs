A API do Chatvolt permite que você integre seus sistemas com Agentes de IA, gerencie conversas, contatos, bases de conhecimento e muito mais.

## URL Base

```
https://api.chatvolt.ai
```

## Formato das Requisições

Todas as requisições devem usar o header `Content-Type: application/json`.

```bash
curl -X GET https://api.chatvolt.ai/agents \
  -H "Authorization: Bearer SUA_CHAVE_API" \
  -H "Content-Type: application/json"
```

## Formato das Respostas

As respostas seguem o formato:

```json
{
  "data": { ... },
  "success": true,
  "error": null
}
```

Em caso de erro:

```json
{
  "data": null,
  "success": false,
  "error": {
    "message": "Descrição do erro",
    "code": "ERROR_CODE"
  }
}
```

## Autenticação

Todas as requisições exigem autenticação via **Bearer Token**. [Saiba como obter sua chave](/pages/authentication).

## Rate Limits

A API possui limites de requisição para garantir estabilidade. [Veja detalhes](/pages/errors).
