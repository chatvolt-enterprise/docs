---
title: 'Logs de Conversa do CRM'
description: 'Registre, liste, consulte, atualize e remova logs de atividade do Flux CRM, mantendo histórico das interações comerciais por conversa.'
openapi: 'GET /crm/conversationLog, POST /crm/conversationLog, GET /crm/conversationLog/{logId}, PUT /crm/conversationLog/{logId}, DELETE /crm/conversationLog/{logId}'
---

## Listar Logs

```bash
curl -X GET https://api.chatvolt.ai/crm/conversationLog \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Criar Log

```bash
curl -X POST https://api.chatvolt.ai/crm/conversationLog \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "conversationId": "conv_abc123",
    "action": "lead_moved",
    "description": "Lead movido para etapa Qualificado"
  }'
```

## Obter Log

```bash
curl -X GET https://api.chatvolt.ai/crm/conversationLog/{logId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Atualizar Log

```bash
curl -X PUT https://api.chatvolt.ai/crm/conversationLog/{logId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "description": "Descrição atualizada"
  }'
```

## Deletar Log

```bash
curl -X DELETE https://api.chatvolt.ai/crm/conversationLog/{logId} \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```
