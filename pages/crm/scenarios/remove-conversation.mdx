---
title: 'Remover Conversa do Cenário'
description: 'Desvincule uma conversa de um cenário (pipeline) do Flux CRM no Chatvolt.'
openapi: 'DELETE /crm/scenario/{scenarioId}/conversation'
---

Remove uma conversa de um cenário do CRM.

## Request

```bash
curl -X DELETE 'https://api.chatvolt.ai/crm/scenario/{scenarioId}/conversation?conversationId=conv_abc123' \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

### Parâmetros

| Parâmetro | Local | Obrigatório | Descrição |
|-----------|-------|:-----------:|-----------|
| `scenarioId` | path | ✓ | ID do cenário |
| `conversationId` | query | ✓ | ID da conversa a remover |

## Resposta

```json
{
  "data": {
    "conversationId": "conv_abc123",
    "scenarioId": 1,
    "removed": true
  },
  "success": true,
  "error": null
}
```

## Dicas

- **O `conversationId` vai na query string**, não no corpo — o endpoint não aceita request body.
- **Remover do cenário não apaga a conversa** — apenas desvincula do pipeline.
- Use ao encerrar o lead (perdido/descartado) para tirá-lo das métricas do funil.
