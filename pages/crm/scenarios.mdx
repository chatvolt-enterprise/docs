---
title: 'Cenários do CRM'
description: 'Gerencie cenários (pipelines) do Flux CRM'
openapi: 'GET /crm/scenario, POST /crm/scenario, GET /crm/scenario/{scenarioId}/conversation'
---

## Listar Cenários

```bash
curl -X GET https://api.chatvolt.ai/crm/scenario \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Criar Cenário

```bash
curl -X POST https://api.chatvolt.ai/crm/scenario \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Funil de Vendas",
    "description": "Pipeline principal"
  }'
```

## Listar Conversas do Cenário

```bash
curl -X GET https://api.chatvolt.ai/crm/scenario/{scenarioId}/conversation \
  -H "Authorization: Bearer $CHATVOLT_API_KEY"
```

## Remover Conversa do Cenário

```bash
curl -X DELETE https://api.chatvolt.ai/crm/scenario/{scenarioId}/conversation \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "conversationId": "conv_abc123"
  }'
```
