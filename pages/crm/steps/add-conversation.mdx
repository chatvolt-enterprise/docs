Adiciona uma conversa a uma etapa do CRM.

## Request

```bash
curl -X POST https://api.chatvolt.ai/crm/step/conversation \
  -H "Authorization: Bearer $CHATVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "conversationId": "conv_abc123",
    "stepId": 2
  }'
```

### Parâmetros

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|:-----------:|-----------|
| `conversationId` | string |  | ID da conversa |
| `stepId` | number |  | ID da etapa de destino |

## Resposta

```json
{
  "data": {
    "conversationId": "conv_abc123",
    "stepId": 2,
    "added": true
  },
  "success": true,
  "error": null
}
```

## Dicas

- Use para **entrada de leads no funil**: assim que a conversa começa, vincula à primeira etapa.
- O `stepId` deve existir no cenário (via `GET /crm/step`).
- Para mudar de etapa depois, use `move` (que atualiza a posição no funil).
